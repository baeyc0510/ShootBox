# ShootBox

UE5 기반 1인칭 슈팅 게임입니다.

## 개요

클래식 아케이드 FPS를 현대적으로 재해석한 게임입니다. 빠른 템포의 전투와 직관적인 조작감을 목표로 합니다.

## 기본 기능

- 캐릭터 이동
- 무기 교체
- 발사

## 구현 예정 기능

- 달리기 (Sprint)
- 조준 (ADS)
- 체력 시스템 + HUD
- 탄약 / 재장전

세부 구현 계획은 [Issues](../../issues)에서 확인할 수 있습니다.

## 브랜치 전략

| 브랜치 | 용도 |
|--------|------|
| main | 안정된 버전 |
| feature/* | 기능 개발 |

